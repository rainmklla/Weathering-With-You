# Weathering With You

A pixel-art weather app prototype with an animated rain loading screen, login and signup pages, and a dashboard with a customizable window theme.

**Live demo:** https://weathering-with-you.vercel.app

## Features

- Loading screen with a canvas rain animation and typing text effect
- Login and signup screens with page transitions
- Dashboard with a window that changes color theme on click
- Retro pixel styling using the Press Start 2P font

## Tech Stack

HTML, CSS, JavaScript (Canvas API)

## Run Locally

No build step or dependencies needed.

1. Clone the repo:
   ```bash
   git clone https://github.com/rainmklla/Weathering-With-You.git
   ```
2. Open `loading.html` in your browser, or use the VS Code **Live Server** extension.

## Status

This is a front-end prototype. Login and signup are visual only, and the dashboard shows placeholder weather values. Planned work includes real weather data from a weather API, saved locations, and activity and reminder pages.
